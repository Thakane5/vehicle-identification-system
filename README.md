# Vehicle Identification System

A JavaFX desktop application for managing vehicles, customers, insurance, police reports, workshop services, and violations. Powered by Supabase cloud database.

## For Lecturers: How to Run

1. Download the entire `distributable` folder from this repository
2. Double-click `run.bat`
3. The application will launch and connect to the cloud database automatically

## Default Login
- **User ID**: ADM001
- **Password**: 1234
- **Role**: ADMIN

## Requirements
- Java 21 or higher
- Internet connection (for cloud database)

## Features
- Dashboard with real-time statistics
- User Management (Admin only)
- Customer Panel with queries
- Vehicle Registration
- Police Reports & Violations
- Insurance Policy Management
- Workshop Service Records
- Role-based access control
